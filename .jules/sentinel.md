## 2025-02-14 - [Command Injection via SystemDialogs::SaveFileDialog]
**Vulnerability:** The function `SystemDialogs::SaveFileDialog` in `CasioEmuMsvc/Ext/SysDialog.cpp` was directly concatenating the user-provided string `preferred_name` inside double quotes to construct a shell command (`zenity` or `kdialog`). Since `popen` is used to run the command, double-quoted strings are vulnerable to command injection if the user input contains shell metacharacters like `$()`, `\`, `;`, or properly escapes the quotes.
**Learning:** In C++ system or popen calls, untrusted inputs should never be placed in double quotes or left unescaped, as these functions invoke the shell directly (e.g. `/bin/sh -c`).
**Prevention:** To avoid this, inputs passed to shell commands must be thoroughly escaped. Implementing and using a shell escape function (like `escape_shell_arg` which replaces `'` with `'\''` and wraps the whole string in `'`) prevents shell metacharacters from being interpreted.
