# GUI font subset

`CasioEmuGuiCJKSubset.otf` is generated by `tools/build_gui_font_subset.py` from
Noto Sans CJK SC Regular and the localized GUI text under `locales/`.

The source font is downloaded from the notofonts/noto-cjk project:
https://github.com/notofonts/noto-cjk

Noto Sans CJK is licensed under the SIL Open Font License 1.1. Keep the license
notice when redistributing generated font files.
