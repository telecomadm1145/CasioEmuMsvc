# GUI font subset

`CasioEmuGuiCJKSubset.otf` is generated by `tools/build_gui_font_subset.py` from
Fusion Pixel 12px Monospaced SC and the localized GUI text under `locales/`.

The source font is downloaded from the TakWolf/fusion-pixel-font release:
https://github.com/TakWolf/fusion-pixel-font/releases

Fusion Pixel Font is licensed under the SIL Open Font License 1.1, with source
tooling under MIT. Keep the license notice when redistributing generated font
files.
